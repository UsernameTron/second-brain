    Create `src/today/compounding-trend.js` exporting a pure `computeCompoundingTrend(rows, opts = {})`.

    Signature: `computeCompoundingTrend(rows, { windowDays = 14 } = {})`. NO I/O — do not require fs, path, os, or any src/ module that touches disk. Add a private `_num(val)` helper identical in spirit to memory-health's: `const n = Number(val); return Number.isFinite(n) ? n : 0;` (so the em-dash '—', '', null, undefined all become 0).

    Algorithm (implement exactly):
    1. Guard: if `!Array.isArray(rows)` treat as `[]`.
    2. Window by ROWS, not calendar days: `const windowRows = rows.slice(-windowDays);` (missed days are gaps, not zeros — never synthesize missing dates).
    3. Insufficient data: `if (windowRows.length < 7) return { verdict: 'insufficient-data', windowDays, rowCount: windowRows.length, metrics: null, rows: windowRows };`
    4. SUPPLY (memory growing): with `first = windowRows[0]`, `last = windowRows[windowRows.length - 1]`:
       - `entriesDelta = _num(last.total_entries) - _num(first.total_entries)`
       - `kbDelta = _num(last.memory_kb) - _num(first.memory_kb)`
       - `supplyOk = entriesDelta >= 5 && kbDelta > 0`
    5. DEMAND (recall used): `daysWithRecall = windowRows.filter(r => _num(r.recall_count) > 0).length`; `recallDayFraction = daysWithRecall / windowRows.length`; `demandOk = recallDayFraction >= 0.40`.
    6. UTILITY (recall returns value):
       - Aggregate: `totalHits = sum of _num(r.recall_hits)`, `totalRecalls = sum of _num(r.recall_count)`; `hitRate = totalRecalls > 0 ? totalHits / totalRecalls : 0`; `hitOk = hitRate >= 0.60`.
       - Week split (deterministic): `const mid = Math.floor(windowRows.length / 2); const week1 = windowRows.slice(0, mid); const week2 = windowRows.slice(mid);` (older half = week1, newer half = week2; odd length puts the extra middle row in week2). Define a local `rate(slice)` = `sum(recall_hits)/sum(recall_count)` over the slice, returning 0 when its recall sum is 0. `week1HitRate = rate(week1)`, `week2HitRate = rate(week2)`; `trendOk = week2HitRate >= week1HitRate - 0.10`.
       - `utilityOk = hitOk && trendOk`.
    7. Verdict: `verdict = (supplyOk && demandOk && utilityOk) ? 'compounding' : 'flat'`.
    8. Return:
       ```
       {
         verdict, windowDays, rowCount: windowRows.length,
         metrics: {
           supply:  { entriesDelta, kbDelta, ok: supplyOk },
           demand:  { daysWithRecall, totalDays: windowRows.length, recallDayFraction, ok: demandOk },
           utility: { totalHits, totalRecalls, hitRate, week1HitRate, week2HitRate, hitOk, trendOk, ok: utilityOk },
         },
         rows: windowRows,
       }
       ```
    These thresholds are Pete's accepted values (2026-07-15, last 14-row window): entries +5 and kb growth; recall used >=40% of days; hit rate >=60%; week-2 utility >= week-1 - 10pts.

    Write the tests in `test/today/compounding-trend.test.js` FIRST (RED), covering every case in <behavior>. Use synthetic row arrays inline — do not read any file. Confirm RED, then implement, then confirm GREEN.
