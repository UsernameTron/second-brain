  <name>Task 1: Create hooks/pre-push-docsync.js blocking gate</name>
  <files>hooks/pre-push-docsync.js</files>
  <read_first>hooks/post-merge-doc-sync.js (exports + main() pattern), config/docsync.json</read_first>
  <behavior>
    - test-count mismatch (exact, any drift) between CLAUDE.md/README.md and live stats -> exit 1
    - coverage drift strictly greater than block_threshold_pct (3.0) -> exit 1
    - coverage drift at or below block_threshold_pct -> warn to stderr, exit 0
    - synced docs -> exit 0, no violations printed
    - getLiveStats returns null (jest failed) -> print notice, exit 0 (never wedge a push on a jest crash)
  </behavior>
  <action>
    New thin file `hooks/pre-push-docsync.js` (separate file, single responsibility — Claude's-discretion
    choice in CONTEXT prefers separate over a mode flag). REQUIRE the three exports from
    `./post-merge-doc-sync` — do NOT re-implement the regexes.

    Logic:
    - Load `config/docsync.json`; read `block_threshold_pct` (default 3.0) and `warn_threshold_pct`
      (default 1.0).
    - `getLiveStats(PROJECT_ROOT)`; if null, write a `[pre-push] could not obtain live stats — skipping`
      notice to stderr and `process.exit(0)`.
    - For CLAUDE.md and README.md: `extractDocStats(text)`, then
      `compareStats(docStats, liveStats, block_threshold_pct)` to collect BLOCKING violations, and
      separately `compareStats(docStats, liveStats, warn_threshold_pct)` for warn-tier drift.
    - If any blocking violation: print each to stderr with a clear `BLOCKED:` prefix, print the
      `SKIP_DOCSYNC=1 git push` escape-hatch hint, and `process.exit(1)`.
    - Else if warn-tier drift exists (present in warn set but not block set): print `WARNING:` lines,
      `process.exit(0)`.
    - Else print `[pre-push] documentation stats are current.` and `process.exit(0)`.
    - No `console.log` (ESLint no-console); use `process.stdout.write` / `process.stderr.write`.
    - Export the pure decision function (e.g. `evaluate(docStats, liveStats, config)` returning
      `{ block: bool, warnings: [], blockers: [] }`) for the test, and run via
      `if (require.main === module) main();`.
  </action>
  <verify>
    <automated>node -e "const m=require('./hooks/pre-push-docsync'); const r=m.evaluate({testCount:100,coverageStatements:90,coverageBranches:80},{testCount:101,coverageStatements:90,coverageBranches:80},{block_threshold_pct:3,warn_threshold_pct:1}); if(!r.block){process.exit(1)} console.error('OK-blocks-on-count')" && grep -q "require('./post-merge-doc-sync')" hooks/pre-push-docsync.js && echo OK</automated>
