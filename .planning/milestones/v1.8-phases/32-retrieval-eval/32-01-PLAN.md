# Plan 32-01: Retrieval Eval Baseline

**Phase:** 32 — Retrieval Eval Baseline (v1.8 Measured Memory)
**Status:** Planned 2026-07-19
**Effort:** ~1 day
**Prerequisite:** `feat/second-brain-capture-verification` merged to master.

## Objective

Make recall quality measurable. Today there is no eval infrastructure at all (verified 2026-07-19: no `eval:*` npm script, no golden set anywhere in the repo). Build a ~20-question golden eval over real memory.md content, scored across keyword / semantic / hybrid modes, runnable as `npm run eval:recall`, with a committed baseline captured BEFORE any tuning. Tuning proposals (semantic threshold 0.55, recencyDecay 0.2, rrfK 60, candidatesPerSource 20 — all in `config/pipeline.json` `memory.semantic`) are a separate later plan gated on this baseline existing.

## Verified ground truth this plan builds on

- Recall logic: `src/recall-command.js` (`runRecall`), CLI at `scripts/recall.js`. Modes: keyword default (minisearch, AND + prefix + fuzzy 0.2, hardcoded `src/memory-reader.js:215-224`), `--semantic` (voyage-4-lite cosine × recency decay), `--hybrid` (RRF k=60). `--top` default 5.
- Store: `$VAULT_ROOT/memory/memory.md` (live: `~/Claude Cowork/memory/memory.md`, 135 entries). Entry identity = `content_hash::` field.
- Embeddings sidecar: `~/.cache/second-brain/embeddings.jsonl`; first semantic call runs `selfHealIfNeeded()` and MUTATES this cache.
- Isolation template: `test/uat/semantic-search.uat.test.js` — temp vault via `VAULT_ROOT`, temp cache via `CACHE_DIR_OVERRIDE`, dual-guard skip when `CI=true` or `VOYAGE_API_KEY` unset.
- Stats hygiene: `runRecall(argv, {_internal: true})` suppresses `recordRecallInvocation` counters.
- Fail-closed gotcha: empty/unloadable `config/excluded-terms.json` blocks ALL semantic queries.

## Deliverables

1. **`eval/golden-recall.json`** — ~20 real questions Pete would actually ask. Each: `{id, query, expected: ["<content_hash>", ...], category?, notes}`. Expected answers keyed by `content_hash` (headings and rank are not stable identities). Coverage mix: ≥3 DECISION, ≥3 CONSTRAINT, ≥5 LEARNING, ≥2 PATTERN; ≥2 multi-word queries that stress keyword AND-semantics; ≥2 paraphrase queries only semantic should catch (keyword misses there are signal, not bugs).
2. **`eval/seed-vault/memory/memory.md`** — frozen snapshot of the evaluated entries with pinned `added::` dates, so recency decay is deterministic and the eval stays reproducible as the live store grows. Golden set version-locked to this snapshot.
3. **`scripts/eval-recall.js`** — harness:
   - Sets `VAULT_ROOT` → `eval/seed-vault`, `CACHE_DIR_OVERRIDE` → temp dir (zero live-cache mutation).
   - Verifies `config/excluded-terms.json` loads non-empty before running semantic (else abort loudly — every semantic query would return `blocked`).
   - Per question × mode calls `runRecall([query, ...flags], {_internal: true})`, top 5.
   - Scores per mode: recall@5 (any expected hash in top 5 = hit) + MRR; prints per-question hit/miss table.
   - Semantic/hybrid skip cleanly with a SKIPPED banner when `VOYAGE_API_KEY` unset (CI-safe).
   - `--baseline` writes `eval/baseline-YYYY-MM-DD.json`; default run compares against newest baseline and prints deltas.
4. **`package.json`**: `"eval:recall": "node scripts/eval-recall.js"`.
5. **First baseline committed**: `eval/baseline-<date>.json` with per-mode recall@5 + MRR.

## Task order

1. Mine memory.md for the 20 questions + expected hashes; record as a human-reviewable table in this phase's notes.
2. Build seed vault snapshot + `golden-recall.json`.
3. Harness skeleton, keyword mode only; prove isolation (live `~/.cache/second-brain/embeddings.jsonl` untouched — assert byte-identical/mtime unchanged).
4. Add semantic + hybrid with the Voyage skip-guard.
5. Baseline run ×2 back-to-back; assert stability (agreement within ±1 recall@5 point); commit baseline with `--baseline`.
6. Docs: eval section in README + rule that any tuning proposal must cite baseline deltas from this harness.

## Constraints

- Assert set-membership / recall@k, never exact rank (`_adjustedScore`, `src/semantic-index.js:269-273`, reorders by recency).
- Never run the eval against the live vault or live cache.
- Eval runs must not pollute recall stats (`_internal: true`).
- Cost: ~155 Voyage embeds first run (seed-vault index), ~40/run after — negligible at voyage-4-lite pricing; no cap needed.

## Verification (deployed ≠ working ≠ correct)

- **Deployed:** `npm run eval:recall` exits 0 on a clean checkout with `VOYAGE_API_KEY` set.
- **Working:** all 3 modes score all ~20 questions; SKIPPED path verified by unsetting the key.
- **Correct:** live embeddings cache byte-identical before/after; two consecutive runs agree within ±1 recall@5; a deliberately-wrong expected hash produces a visible miss (the harness cannot silently pass).
