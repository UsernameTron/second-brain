<objective>
Add the contradiction check at promotion (roadmap bullet 2): when a candidate is promoted, hybrid-search the existing store for the top 5 nearest entries and ask Haiku whether the new entry contradicts any of them — FLAG ONLY, never block, never auto-resolve. Build it as the shared helper the dream STALE detection reuses (ordering constraint: "the shared contradiction-check helper precedes the dream work — build once, promotion gate and dream both call it").

Purpose: surface likely contradictions to the human at the moment of promotion without ever mutating or blocking, and give dream STALE a ready-made detector.
Output: `src/contradiction-check.js` helper + flag-only wiring into the promotion path.
</objective>

<constraints>
- FLAG-ONLY. The check must NEVER block promotion, NEVER auto-resolve, NEVER edit either entry. Its only effect is a line in the promotion report.
- Never-throws: the LLM client is the never-throws `createHaikuClient()`; if Voyage is down `hybridSearch` may return few/no results — degrade to `contradicts:false`, do not throw, promotion continues.
- Shared: the SAME `checkContradiction` is what dream STALE detection (Plan 05, DREAM-CONSOLIDATION-DESIGN.md:54-56) calls. Do not fork it there.
- No `console.log` in production code.
</constraints>
