- STALE age criterion applies ONLY to ephemeral categories (whitelist in config/memory-categories.json); NEVER CONSTRAINT / PREFERENCE.
- Reuse the shared `checkContradiction` (Plan 34-04) for STALE contradiction detection — no second implementation.
- Config values are LOCKED (see below) — do not tune.
</constraints>
